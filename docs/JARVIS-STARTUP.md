# JARVIS: запуск на Windows 10

Рабочая копия: `D:\JARVIS-test`. Постоянную установку в `D:\JARVIS` не выполнять.

## Один запуск

В PowerShell из рабочей копии:

```powershell
python jarvis_launcher.py --open-browser
```

Это запускает локальную панель на http://127.0.0.1:8765 и открывает браузер. Микрофон выключен.

Для пробуждения голосом (требуется заранее установленная русская модель Vosk, Python-пакеты `vosk` и `sounddevice`):

```powershell
python jarvis_launcher.py --vosk-model "D:\JARVIS-test\models\vosk-ru" --speak
```

Укажите действительный путь к модели. Слушатель работает только пока запущен процесс. Фраза «Джарвис, привет» открывает браузер; приветствие озвучивается через SAPI (не обязательно голосом «Руслан»).

## Безопасность

Автозагрузка Windows НЕ создаётся автоматически. Чтобы остановить прослушивание, нажмите Ctrl+C в окне процесса. Чтобы не запускать микрофон, не указывайте `--vosk-model`.

Если когда-либо будет включена автозагрузка, она должна быть обратимой и настраиваться только после тестирования.
