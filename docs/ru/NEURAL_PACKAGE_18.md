# Пакет 18 — интеграция управления моделями

NeuralModelController связывает Model Registry, Model Lifecycle, Resource Governor и оценку кандидатов. Активация возможна только для состояния READY и после прохождения тестов. Откат допускается только к подготовленной версии; активную модель нельзя выгружать.

ProcessMemory предоставляет текущий RSS процесса Python: Windows через системный API, Linux через /proc/self/status. Это диагностическая метрика, а не физическое ограничение RAM и не суммарная память Ollama.

Ограничения: реальные веса и процессы моделей пока не загружаются и не переключаются. Тесты: tests/test_neural_model_controller.py.
