# Пакет 12: планировщик Neural Core

Реализован ограниченный приоритетный планировщик фоновых задач с пятью приоритетами, дедлайнами, резервированием памяти через Resource Governor и диагностическими счётчиками.

Планировщик кооперативный: не прерывает выполняющуюся задачу, не создаёт поток автоматически и пока не подключён к голосовому ядру. При недостатке логического бюджета задача остаётся в очереди.

Тесты: tests/test_background_scheduler.py. Следующий этап — интеграция с реальными фоновыми задачами и ограничениями ОС.
