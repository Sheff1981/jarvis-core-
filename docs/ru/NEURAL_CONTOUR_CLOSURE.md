# Neural Core — закрытие архитектурно-программного контура

Дата: 2026-10-16.

## Решение

Контур закрыт в согласованном объёме: архитектурный фундамент и изолированный интерфейс инференса. Последняя контрольная сборка bf1919e; GitHub Actions #1313 — success. Расширение данного контура остановлено, возврат к основной дорожной карте.

## Реализовано

ResourceGovernor, BackgroundScheduler, ModelRegistry и JSON-хранилище, ModelLifecycle, Evaluation и SafeModelPromotion, NeuralModelController, OllamaAdapter, CallableAdapter, NeuralRuntime, измерение задержки/RSS процесса, shadow-оценка, тесты восстановления после исключения модели.

## Не входит в акт закрытия

Не заявлять собственные обученные веса, рабочий ONNX-движок, полную интеграцию в голосовой тракт, фактическое управление RAM дочерних процессов или аппаратную приёмку Windows. Эти работы остаются отдельными задачами дорожной карты. Не менять main. Обновление ноутбука — после «Выгружаем».
