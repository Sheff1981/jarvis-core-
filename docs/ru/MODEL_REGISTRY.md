# Model Registry — пакет 13

Реализован реестр метаданных моделей с версионированием, активацией и откатом к предыдущей версии. Повторная регистрация версии запрещена. Доступны снимок состояния и перечень версий.

Это реестр в оперативной памяти: он пока не загружает модели, не переключает работающие движки и не сохраняет состояние на диск. Интеграция с Resource Governor, постоянным хранилищем и оценкой качества — следующие этапы.

Тесты: tests/test_model_registry.py.
