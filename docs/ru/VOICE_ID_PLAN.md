# JARVIS Voice ID — пакет локальной идентификации владельца
Дата: 2026-10-16. Статус: КОНТРАКТ ГОТОВ, ПОЛНАЯ ИНТЕГРАЦИЯ НЕ ГОТОВА.

Цель: исключить реакцию на телевизор, других людей и постороннюю речь без облака. Реальная идентификация владельца требует аудиообразцов владельца и локальной модели speaker verification. Vosk распознаёт слова, но не личность. EnergyVAD различает энергию/тишину, но не говорящего.

## Пакет внедрения
1. Локальная запись согласованных эталонных фраз (разные расстояния/интонации), отказ от хранения сырых записей после извлечения признаков по выбору владельца.
2. Локальная модель извлечения speaker embeddings, сравнение с профилем, настройка порога и тест на ложные срабатывания; оценить производительность на CPU 8 ГБ.
3. Проверять говорящего **до** помещения команды в очередь VoiceSession, а не по распознанному тексту; на неверный голос — игнорировать, без ответа.
4. Для телевизора, фоновой речи, шума и записанного голоса — негативные тесты; запись владельца не может гарантированно отсечь одна биометрия, поэтому опасные действия требуют отдельного подтверждения.
5. Микрофон, Vosk, wake word, Piper и Ollama должны сохранять работоспособность; по умолчанию старое поведение, а при включённом Voice ID без профиля — fail closed.
6. Не отправлять голос, отпечатки и приватные аудиоданные в GitHub; хранить локально с ограничением доступа и возможностью удалить профиль.
7. Windows/Ubuntu CI, затем физическая приёмка на ноутбуке после «Выгружаем».

## Реализовано
- jarvis/speaker_gate.py: строгий контракт SpeakerGate и SpeakerDecision, запрет при отсутствии профиля, сбое и недопустимых данных.
- tests/test_speaker_gate.py: unit tests.
**Важно:** текущий контракт НЕ создаёт голосовой отпечаток и НЕ подключён к микрофону; фильтрация телевизора пока не работает. Нельзя выдавать этап за готовый.
