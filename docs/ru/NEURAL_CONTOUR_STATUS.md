# Neural Core — единый контур

Дата: 2026-10-16. Состояние: РАЗМОРОЖЕН, ИНТЕГРАЦИЯ В РАБОТЕ.

## Реализовано

Логический ResourceGovernor, очередь фоновых заданий, реестр и сохранение метаданных моделей, жизненный цикл, проверка качества, защищённое продвижение и откат, локальный Ollama Adapter, замер задержки/RSS, shadow-проверка. NeuralRuntime объединяет реестр, жизненный цикл и подключаемый backend в отдельном опциональном интерфейсе. Операции активации, отката и выгрузки синхронизированы.

## Не подтверждено

Работа NeuralRuntime с настоящим Ollama на ноутбуке, загрузка весов через lifecycle, аппаратная память дочерних процессов, целевые задержки, обучение собственных весов, интеграция в основной голосовой тракт. Эти функции не считать завершёнными. Ветка main не изменяется.

## Критерий завершения контура

Автотесты Windows/Ubuntu; проверка реального локального Ollama и ошибок сети; испытание памяти и нагрузки на ноутбуке; документированный откат; интеграция с действующим JARVIS только через явно включаемый интерфейс. До этого статус — НЕ ПРИНЯТ. Ноутбук обновлять только после команды «Выгружаем».
