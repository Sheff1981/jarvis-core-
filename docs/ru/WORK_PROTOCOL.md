# JARVIS CORE — обязательный порядок разработки
Дата введения: 2026-10-16. Рабочая ветка: feature/dialogue-project-memory. main не изменять.

## Единственный источник прогресса
Перед началом любой работы прочитать docs/JARVIS_ROADMAP.md, docs/ru/CURRENT_STATUS.md и последнюю запись docs/ru/DAILY_LOG.md. Английские зеркала: docs/en/. При расхождении приоритет у проверенных коммитов, тестов и фактического состояния системы, а не у текста.

## Правило одного этапа
Одна активная задача. Новые идеи — в очередь без переключения. Переключение только после явного подтверждения владельца. Этап закрывать только по критериям приёмки, CI и требуемым проверкам на ноутбуке/сервере.

## После каждой рабочей сессии
Обновить CURRENT_STATUS и DAILY_LOG в обоих языках. Записывать дату (YYYY-MM-DD), время и часовой пояс если известен, выполненное, SHA коммитов, проверки и их результаты, блокеры, точку остановки, одно следующее действие. Не выдумывать часы, тесты и выполненные действия. При отсутствии подтверждения писать «не проверено». Не хранить пароли, токены и персональные данные в GitHub.

## Синхронизация
GitHub хранит исходники и документацию, но не рабочую SQLite-память и не секреты. Ноутбук и сервер обновляются только после тестов, с резервной копией и откатом. Установка на D:\\JARVIS запрещена до отдельного решения.

## Обучение
Накопление данных и словарей не равно обучению весов. LoRA/QLoRA — отдельный будущий этап с разрешёнными данными, базовыми метриками, арендой GPU, проверкой и возможностью отката.

## Способ установки и обновления (решение владельца, 2026-10-16)
Не создавать EXE-установщик JARVIS. Развёртывание, обновление, запуск и диагностику выполнять через PowerShell с получением исходников из существующего GitHub-репозитория. Использование необходимых сторонних исполняемых компонентов (например, piper.exe) допустимо и не означает создание EXE-установщика JARVIS. До обновления сохранять резервную копию и возможность отката. Тестовая папка: D:\\JARVIS-test. Не выдавать команды установки до сигнала владельца «Выгружаем».
