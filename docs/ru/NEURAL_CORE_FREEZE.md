# Neural Core — заморозка архитектурной серии

Дата: 2026-10-16. Серия пакетов 11–21 завершена на уровне изолированных модулей, тестов и документации; итоговая проверка CI последнего пакета обязательна.

## Состав

11 — Resource Governor; 12 — Background Scheduler; 13 — Model Registry; 14 — JSON persistence; 15 — Model Lifecycle; 16 — Evaluation; 17 — Safe Promotion; 18 — NeuralModelController и ProcessMemory; 19 — локальный Ollama Adapter и интерфейс CallableAdapter; 20 — замеры задержки и RSS; 21 — изолированная shadow-оценка кандидатов.

## Строгие ограничения

Это НЕ готовая собственная нейросеть. Нет обученных весов, ONNX-исполнителя, автоматического переключения Ollama, реального лимита памяти процессов, подключения к голосовому тракту и аппаратной приёмки. Реестр и жизненный цикл управляют метаданными и логическим состоянием. Shadow-оценка не меняет ответы пользователя.

## Решение

После подтверждения CI прекратить расширение Neural Core до закрытия N0. Работать по docs/ru/VOICE_N0_ACCEPTANCE.md. Команда владельца «Выгружаем» обязательна перед обновлением ноутбука. Основную ветку main не менять. Следующие изменения Neural Core — только по отдельному решению после реальной приёмки и аудита.
